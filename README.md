## 概要

作者個人の好みや日記などを残せる静的なサイトを作成した。
また、バイブコーディングでどのようなものが作成できるのかを学集する目的で、生成AIを多用している。

## 使用技術

HTML
CSS
JavaScript
生成AI(Gemini3の思考モード)

## 注意点

このサイトはnetlifyを使ってインターネット上で閲覧することを想定しているため、ローカル環境だとメニューバーが表示されません。
ご注意ください。
[https://shibainu-scrapbook.netlify.app/](https://shibainu-scrapbook.netlify.app/)

## こだわったポイント・工夫など

「日記をイメージしたサイトを作りたい」というコンセプトから、配色や枠の取り方、付箋をイメージしたメニューバーを生成AIと対話して作成した。
また、追加ログを残しておくことで、閲覧者がより変化を感じやすいようにしている。
